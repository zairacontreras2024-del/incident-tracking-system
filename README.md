# Incident Tracking System

A safety incident tracking application designed to help organizations record, manage, and analyze workplace incidents, near misses, and corrective actions.

## Features

- Record workplace incidents
- Track near misses
- Assign corrective actions
- Generate safety reports
- Monitor OSHA metrics
- Dashboard analytics

## Technologies

- Python
- SQLite
- GitHub
- SQL

## Project Goals

This project demonstrates software development, database design, and safety management concepts by creating a practical incident tracking solution for industrial and construction environments.

## Future Enhancements

- User login system
- PDF report generation
- Power BI integration
- Email notifications
- OSHA recordable calculations
